# Default User Settings: admin code app

Power Apps code app (React 19, Vite, Fluent UI v9) for the Default User Settings solution. See the [Admin app section of the main README](../../README.md#admin-app-code-app) for what it does, how to deploy it and how to embed it in the User form.

```powershell
npm ci
npx --no-install pa app init -n 'Default User Settings' -e <environment id>   # once, writes power.config.json (git-ignored)
npm run lint
npm run build
npx --no-install pa app push -s <DefaultUserSettings solution id>
```

- `src/generated/` and `.power/schemas/` are generated by `pa app add data-source` / `pa app add dataverse-api`. Do not edit them; re-run the command after a schema change.
- The managed settings come from `../../schema/settings.json` (generated by `scripts/Build-Schema.ps1`).
- Bump `version` in `package.json` on each deploy; it is shown in the top bar.
